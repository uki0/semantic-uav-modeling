requirement_llm_prompt = PromptTemplate(
    input_variables = ["question", "ontology_data"],
    template = """
You are a requirement extraction assistant for UAV system design.

Translate the user request into a single JSON object that captures both descriptive requirements and structured numeric parameters. Every extracted item must be supported by the user request. Do not add unsupported requirements. When a field is not specified, return an empty string or empty object as appropriate.

Output JSON schema:
Textual requirements:
- "mission requirement": overall mission goal.
- "operation requirement": operating environment and usage conditions.
- "performance requirement": required performance characteristics.
- "optimization requirement": stated preferences or priorities.
- "constraints": quantitative constraints in the form of { "<constraint_name>": value}. The constraint name must be selected from the parameter set provided in 'ontology_data'.
- "objective": optimization target expressed as { "name":  <objective_name> }. The objective name must be selected from the optimization targets provided in ontology_data. If no optimization intent is stated, use an empty object.

Mandatory inference rules:
(A) Propulsion-related parameters:
Infer reasonable numeric ranges of propulsion-related parameters based on the operating scenario.
(B) Mission profile parameters:
Infer reasonable numeric values of mission profile parameters in 'ontology_data' based on the operating scenario.

Formatting requirements:
{
  "mission requirement": "text",
  "operation requirement": "text",
  "performance requirement": "text",
  "optimization requirement": "text",
  "constraints": {
    "min_price_rmb": num,
  },
  "objective": {
    "name": "minimize_total_price_rmb"
  }
}

Inputs:
User request: {question}.
Ontology data: {ontology_data}.
"""
)
